# 历史实验的参考源码

A.I.R.、VCD 和 VideoHV-Agent 各保留旧来源审计使用的两个源码文件。原许可证或上游授权说明随各目录保存。读取路径以工程内目录为准；audit.json 记录最初实验的来源路径、提交和文件摘要。verified_audit() 会校验实际文件。

upstream.json 固定六个上游版本。四份 Git 补丁保存原检出的执行权限变化；需要恢复参考工程时，在对应上游提交上执行 git apply 对应补丁。

relocations.json 的每对 SHA-256 分别对应迁移后的脚本和原始脚本。仅当前者完全匹配时使用原协议身份，供冻结实验读取既有检查点。更改后的其他版本按其实际摘要处理。
