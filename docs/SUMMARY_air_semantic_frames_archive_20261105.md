# A.I.R.启发的语义选帧：阶段归档与系统边界

更新：2026-11-05，feat/air-visual-evidence。停止本轮调参和新增判决/选帧规则；冻结“去观察查询”低成本候选。没有启动新的推理或扩样。旧代码、结果、缓存和失败记录全部保留。

## 1. 当前成果到哪一步

已经完成独立的、问题相关的时间帧选择工程：真实视频1fps粗图像特征＋完整问题/四选项/显式子事件的CLIP查询→固定规则选择6个12秒窗口、每窗口4帧→合并8帧全局锚点→最多32帧按原时间输入原Mage→最终QA。共享向量直接复用；没有字幕、API、Agent、训练、答案覆盖或新的神经融合层。

原A.I.R.适配使用本地CLIP-L/14、Mage分析和回答，属于有差异的移植，不是原论文官方成绩复现。最终低成本候选进一步移除Mage短观察查询及证据判决，只保留完整原题及显式子事件检索与固定窗口规则，准确称为“A.I.R.启发的问题相关时间选帧候选”，不要称为原A.I.R.全流程或已验证的完整条件证据融合算法。

完成了运行闭环、输入身份校验、断点/tqdm、成本追溯及多个对照。存在局部纠错，但尚未证明一般题目或独立测试上稳定涨点。保留候选不等于批准全量评测。后续若继续，只能冻结规则后另行验证，不按本次答案继续挑规则。

## 2. 实验结论

早期原A.I.R.适配：前90题均匀56、A.I.R.56；新增90题均匀54、A.I.R.51。合计180题均匀110、A.I.R.107。固定16全局＋16局部混合：前90题58、新增90题53，合计111，仅比均匀多1题。早期首90源评分有2条格式非法，旧源审计失败记录保留，混合版本明确排除非法评分，不包装成完全无警告的原A.I.R.复现。

人工/助手定位诊断12题：均匀4、人工定位画面8；属于已见事后诊断，部分证据不确定或视觉不足，不能当方法成绩或严格数学上限。只支持“证据定位可能有空间”，不保证自动定位能达到。

复杂报告v1：12题96个任务中88个最终报告非法，11/12联合报告非法，停止。v2约束状态码解决结构问题，但240段短观察中87段只有A/B/C/D；充分性自述、跨片段一致性不可靠。语法约束不等于事实核验，不继续开发该判决器。

同一30题/29视频直接QA（中等15、长15），三个版本均通过输入审计，非法答案0：

- 均匀32帧：16/30，53.33%。
- 带观察查询的v2选帧：19/30，63.33%；相对均匀救回6、误伤3，净增3。
- 去观察查询：18/30，60.00%；相对均匀救回4、误伤2，净增2，+6.67个百分点；视频簇95%区间[-6.67,20.00]，跨零。

去观察查询分组：中等9→10/15；长视频7→8/15。原诊断12题4→6；新增18题12→12，救回0、误伤0，逐题对错与均匀一致，不表示答案字母逐题一致。带观察v2在新增18题为11/18，去观察仅修复其中1次误伤；旧12题则少对2题，不能把“观察污染”确认为主要失败原因。

低成本候选1题与v2输入不变复用，29题新增QA；消融没有480次证据调用，也没有新增图像或文本编码。共享CLIP特征的原始编码、视频解码和最终QA仍有非零部署成本，不宣称免费选帧或实测端到端加速。

30题全部来自原开发180题，原12题按诊断案例选择；不能将总分提升写成独立泛化收益。当前结果不足以进入全量或宣称稳定改进。

## 3. 与原Mage“选区”的关系

本模块在视觉编码之前决定“视频的哪些时刻进入Frames输入”，是时间帧级证据组织。原Mage仍负责原生像素处理、Mage-ViT视觉编码与原多模态解码；保留真实原帧号/秒数和原生输入一致性。

没有修改原生Codec引导的稀疏patch处理、图像内ROI选择、模型权重或注意力结构。不能写成“A.I.R.替换/增强了Mage的Codec选区”，也不是旧QueryIP/CLIP图像区域选择复活。Codec与Frames是原本可对照的输入路线，当前候选只接在Frames分支，不存在已实现的双路融合或自动门控。

语义体现在问题/选项条件下的检索与时间选择；“语义融合”如用于论文需明确指输入证据组织，不能暗示新的可训练跨模态融合网络、可靠事实验证或语义理解已经被证明。

## 4. 与时间对齐字幕模块的关系

二者是面向同一个Mage问答核心的两个独立输入模块：视觉模块解决“看哪些时间画面”，字幕模块解决“给哪些对应解说文本”。当前分别实现、分别评测，尚未验证二者组合；不能把两次分别提升相加。

字幕已冻结Frames-32＋连续补句＋时间标记、2048字幕token，独立test225中无字幕140/225，连续字幕163/225，净增23题/+10.22个百分点，簇区间[5.33,15.11]。相对原对齐154/225多9题/+4个百分点，区间[-0.44,8.46]仍跨零；不能把连续补句的独立优势写成显著。详见SUMMARY_mage_subtitle_final_results_20261103.md。714题是本地互斥覆盖，不是714道独立测试或官方全基准。

两模块未来可连接，但字幕必须根据新的实际选中帧秒数重新匹配/补句，不能复用均匀32帧的旧字幕包当成新帧对齐输入。组合后文本可能改变，视觉和总token也需实测记录。联合配置尚未实现/评测，不能标“已验证的语义选帧＋字幕融合系统”。

## 5. 对用户两张示意图的准确解释

第一张“Visual Sampling + Subtitle Alignment → Mage-VL”适合作为系统设计，但Visual Sampling应标“均匀32帧（字幕已验证配置）/语义选帧（冻结候选）”；不应暗示64帧或自适应选择已稳定提升。字幕对齐模块应依赖实际采样时间，不是完全独立于帧时间的并行支路。

第二张“A.I.R. Visual Evidence Selection → Mage-VL”可描述实验性视觉前端；准确标签是“A.I.R.-inspired temporal frame selection”。被红色遮挡部分不可推断内容；若拟表示字幕模块，应标“独立已验证，联合待验证”。当前没有额外的证据裁判或答案覆盖模块。

## 6. 可写与不可写的成果

可写：实现免训练的问题相关时间选帧适配、固定预算窗口组织、原时间保持和可追溯配对评测；在已见30题开发诊断中观察到18对相对16对的局部收益，并披露新增18题持平及不确定区间。字幕作为已有测试收益支持的系统增强模块单独报告。
