# Codec完整字幕dev180实施（2026-11-06）

## 预算变更依据与授权

原6144主路线在60视频预检中有15视频/45题超限；仅命中句及时间标记已需6956—12142 token。未跳题、未截断，清单保留preflight/budget_blockers.json。用户随后明确选择“完整证据优先：统一提高预算，先测显存”。

CPU检查60视频全部来源命中句、原邻接补句和时间标记，最大完整文本13043 token，因此全体统一采用13312字幕token预算。此预算只由输入完整性确定，不读取问答得分；本批主路线不省略任何候选邻句。32来源锚点/2048对照保持原规则。视觉patch、原生Codec和QA提示保持不变。与旧6144属于不同固定协议，旧9题和6144结果原位保留，不合并冒充相同预算。

## 固定范围与输入

已有dev180/60视频，全中长视频，不是60道题，不包含test225。三路：原生Codec无字幕；Codec全部来源时刻＋完整邻句/时间标记、13312预算；Codec均匀最多32个字幕来源锚点＋2048。保留旧Frames连续字幕2048参考。最多540逻辑答案，相同完整输入才同题复用，缺字幕精确回退。

每视频原Codec缓存只读复用，禁止底层重建/删除。14项CPU测试通过。CPU输入审计核对每题原生Codec无字幕旧prefix、视觉布局，三路视觉Tensor完全相同，原生展开与插槽构造一致。GPU还会核对保存的完整Tensor SHA。

最长视频由字幕token＋视觉token选出，elprD1hnDyU，702/703/704三题。probe先生成这三题共9逻辑答案，检验原无字幕控制复现、答案合法和峰值显存小于设备总显存90%。探测结果直接计入dev180。通过才允许run；OOM、非法答案或控制不复现会保存已有断点和日志并停止，不自动降预算/跳题。
