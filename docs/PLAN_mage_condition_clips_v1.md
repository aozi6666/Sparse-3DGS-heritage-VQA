# 自动完整条件＋多帧片段验证：小规模可行性v1

2026-11-04；feat/air-visual-evidence。只验证自动证据检索/说明能力，先不生成最终问答答案、不覆盖旧答案，不进入全量。

使用既有12题，题号379/418/484/626/265/450/486/704/325/454/625/655，属于已见事后诊断集，不是独立测试。自动上下文只读取既有Video-MME问题、原始视频和旧CLIP全视频1fps特征/元数据，禁止读取oracle输入帧、人工时间段、评审说明或GT。人工定位只在全部自动任务完成后的离线评估中读取，不参与检索、提示或选片。

冻结流程：每题8帧全局概览→Mage生成可见事实/缺证据/最多4个搜索对象→使用本地原CLIP文本编码器编码完整原问题及搜索对象，复用旧视频特征→自动提议6个12秒片段，每片段4帧。问题含首次/开头时固定按时间从0秒/12秒开始的两片段优先；最终/结尾则从尾段逆向两片段优先；其他按多个查询轮流取高相似且时间不重叠窗口。无足够检索窗口时用全局均匀窗口补足，不按题号/真值开关。

每个局部调用联合看到其4帧＋8帧全局概览（保留原时间/帧号），需输出结构化可见事实、已满足条件、缺少的证据与模型支持判断。最后联合最多32帧（全局8＋片段24）和本轮局部报告做一次跨片段核查。固定8次调用/题（1概览+6片段+1联合），共96次逻辑调用，每次最多384新token；仅格式失败时允许一次独立留档的修复尝试，最多192实际调用。绝不把格式非法伪造成中性/低分，不无限重试。

完整条件从原问题自动提取，包含目标和候选区分，自动识别first/beginning/final/end/order/whole-video/multiple等限定；不把“空间同场排列”一概当跨视频时序。模型仍看到完整原问题和四选项。结构校验仅验证JSON与引用帧存在，额外检查首次需有开头连续窗口、最终需尾段、顺序需跨窗口多帧依据。它不能证明语义事实/完备性真，输出始终标记非机器认证；不足条件必须报告insufficient/partial，不能把中途领先当最终胜利。

固定max_pixels150000/min3136、同一Mage、greedy/seed0，本地CLIP权重，不引入训练/字幕/API/新权重。联合32帧只是本轮核查预算，不发布最终QA准确率。每调用/文本向量/候选窗口独立断点，tqdm、GPU共享锁、完整费用和来源SHA。新成果统一在18_air_frames_v1/condition_clips_v1/，旧代码/结果不改。保留10GiB、整个AIR根1GiB保护，不保存原始帧或权重。

全部12题任务完整后才离线对比人工定位：明确证据子集、每个证据区间覆盖、最近帧时间差、结构有效率、声称充分/实际缺条件案例。时间覆盖不等于语义正确，不能将人工时间匹配称自动验证准确率或涨点。优先人工查看原始事实和缺证据字段，确认自动窗口真实支持题意，才决定后续是否做32帧自动QA。
