## 2. 输入与来源

复用condition_text30_offline_reaudit_v1最后缓存的查询，校验其候选协议、逐题SHA与审阅包范围SHA。保持事件ID、列举顺序、明确范围、已知before与未知关系。读取原始无标签问题清单定位视频文件；不读取GT、旧QA预测、人工证据范围，不调用解析API。

图像特征精确复用native_uniform_fix1及extension90已缓存的1fps coarse.npz，核对原签名、视频ID、索引SHA、历史noobs特征SHA、视频文件大小/mtime、fps、帧数、768维投影和有限非零数值。CLIP配置与权重stat身份必须与原缓存相同；不重复图像编码、不复制视频或权重。

文本仅对缺失的精确字符串编码。旧v2文本如存在完全相同查询且CLIP身份一致，复用其向量、token chunks和来源SHA；不通过删除标点或模糊匹配声称复用。编码方式沿用既有CLIP-L/14、FP16、77-token分块、单位向量均值后归一化，再FP16落盘重放；原始查询不截断。模型/依赖离线，不安装、不下载。

## 3. 固定定位规则与时间约束

1. 每个叶事件记录全部1fps原始cosine曲线、相对min-max曲线及3个相隔窗口的原始峰。分数不是概率或证据充分性。
2. 至多4个叶事件各先分配一个12秒窗口，允许同一峰窗口共享，再按叶事件轮流补到6个不重叠窗口。每窗口均匀4帧，加原生torch linspace round生成的8个全局锚点，拟议输入最多32帧。窗口分配成功不等于叶事件正确。常数曲线、范围不足等明确记录不可定位并保留原回退。
3. 625未知顺序不构造SEQ、不按a/b/c/d预设时间。484各作品独立检索，并额外报告同一原帧上的最小叶事件相对分数峰，仅作“是否可能同场”的探测，不据此认定四作品齐全或空间排列正确；不改变6窗口选择规则。
4. 549只使用题面已给q2早于q1。通过严格递增原帧的最优数值时间对保证before；同时保留原独立峰，便于观察约束是否牺牲目标匹配。数值顺序正确不证明两个事件识别正确，更不能回答原因。
5. 406保留unknown_successor操作符，单独定位给定爬高台事件，不生成未知后续事件，也不承诺后续过程已覆盖。4题anchor_only的原QA回退不变。
6. 明确数字范围若用于活动题，先限制候选、窗口和锚点，再求已知先后关系；不会先在范围外选峰再强裁。当前带0–360秒范围的543属于原回退，不因诊断而改变其旧输入。

本轮没有QA选择提交。7题产生的最多32帧只是拟议诊断输入；4题也只作探测；所有旧QA结果与输入保持原位。定位可行性审阅通过后，才能另立固定QA对照。

## 4. 可审阅输出与省盘

统一目录：`VQA/eval_results/practical_mage_v1/18_air_frames_v1/condition_leaf_localization_probe_v1/`。

- candidate.json：源码、范围、查询、缓存/模型/视频身份和固定预算。
- text_features：每个唯一查询一个带SHA的文本向量，小型JSON，可恢复；只编码缺失项。
- curves：压缩NPZ原始/相对曲线，不复制图像矩阵。
- locations：30题记录（含19题精确回退），原峰、受约束位置、窗口、源帧索引与原noobs输入。
- previews：仅11题缩略图。comparison.jpg对照原noobs与拟议输入；peaks.jpg展示各叶事件3个原峰及必要同场探测。原峰有时不在拟议32帧中，额外缩略图只供诊断，绝不是额外QA输入。报告原峰是否被采到及最近输入帧时间差，避免把窗口对了等同于画面证据到位。
- 解码只取这些原帧，不写视频切片、逐帧图片或原始数组；缩略图JPEG保存，预计新增通常为数MB级，实际占用由磁盘检查控制。
- results/summary.json、review_packet.json、review.html、manual_review_template.json：逐题查询/约束/时间/画面对照。人工审阅模板仅供事后诊断，不会被选择器读取，不新增评测数据集。

预览记录frame/fps与decord实际PTS并核对漂移；差异超过max(0.1秒,2/fps)即停止，不能用错误时间轴凑结果。所有预览都要对应记录的原视频和原帧。

## 5. 断点、成本和质量检查

各阶段独立恢复：文本向量、曲线、定位记录、缩略图及报告不覆盖旧内容；文件损坏/身份漂移直接停止。新文件以本次临时文件原子提交，只清理本函数刚建的临时文件，不清理已有数据。图已保存、预览记录尚未保存时中断，可重建同内容图后补记录。GPU共享锁防止与旧实验同时占卡。

每次入口检查分支、df、相关du，少于10GiB或AIR目录超过1GiB停止；禁止自动清理。禁止联网、env/密钥、GT、旧QA账本和人工时间段读取。CPU预检只校验现有缓存，不加载模型或解码真实视频。用户执行encode才加载本地CLIP；render只进行CPU预览解码。助手仅做静态检查、纯CPU模拟测试与预检。

成本保留：新增文本编码、历史唯一视频图像编码、缩略图解码均单列。缓存复用不是部署零成本；本轮预览/来源验证也不是部署速度测试。
