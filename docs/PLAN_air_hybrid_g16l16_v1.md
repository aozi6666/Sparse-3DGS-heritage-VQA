# 单候选：16全局锚点＋最多16局部代表，固定32帧

2026-11-04；分支feat/air-visual-evidence。此计划先于候选代码建立。

只处理既有dev30的90题，原始AIR/均匀32结果、脚本、审计均原位保留。独立入口air_hybrid.py/run_air_hybrid.sh；新成果放18_air_frames_v1/hybrid_g16l16_v1/。不引入数据集、字幕、训练、API或额外评分，不改变原Mage处理器和问答提示词。回退只需使用原run_air_frames.sh，原入口完全不修改。

冻结规则：从本轮原生uniform32的32个帧号中，以torch.linspace(0,31,16).round()的位置取16锚点，含首尾。其他候选来自已缓存、合法解析为4/5分的已评分帧，排除锚点。相邻时间差≤2秒归同簇，跨簇轮流取代表；簇按最高分、最高CLIP相似度、最早帧号排序。各簇第一帧按分数、CLIP相似度、原帧号选；后续选距本簇已选帧最远的帧，分数/相似度/帧号打破并列。局部最多16，不能重复；不足从原uniform32剩余帧按原时间顺序补齐。最后恰好32帧并按原帧号排序。参数只有这一组，不按真值/题型/已知救回误伤设开关。

两个非法历史评分保留且排除，不擅自当中性或修正旧审计；报告继承源审计警告。复用source context身份校验、原始视频stat、模型/提示词与代码SHA，冻结每题规划和分数来源哈希。原90个uniform答案直接复用；若新索引与已存在uniform/AIR索引相同，在真实输入重新构建并核对来源和元数据后复用对应答案，否则只生成1次新最终QA。绝不重跑5517次评分/CLIP。原运行没有保存像素tensor哈希，因此不得声称与历史像素逐位相同；本轮原生/适配均匀路径逐tensor相等，新输入记录全部tensor哈希。

所有新答案逐题封存/fsync、tqdm、共享GPU锁、普通断点恢复、损坏停止不清理。至少保留10GiB空闲，AIR根目录上限1GiB；不保存帧图/权重/视频。完整90题后才读标签，三路比较（uniform、原AIR、hybrid）、救回误伤、视频聚类区间、14诊断题/其余76题分组、实际token与生成成本；旧选择费用单独完整列出，缓存复用不等于部署免费。

先做CPU规则/身份/恢复与预处理回归，离线生成90题规划，再由用户启动GPU。助手不启动推理。收益未验证；若持平且成本高，暂停AIR。该90题已用于诊断，不能称独立测试。
