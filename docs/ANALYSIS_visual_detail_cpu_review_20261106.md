# 视觉细节CPU审阅结论（2026-11-06）

## 决策

暂不开发视觉细节增强模块，不启动GPU分辨率对照。本次固定8题中，明确满足“完整正确证据已入帧、原图可辨而150000像素输入不可辨”的案例为0；405仅保留为弱候选。此结果是不进入下一阶段的工程依据，不是否定所有分辨率增强方法。

## 范围与方法

固定已有dev180连续字幕答错的8题：294、298、405、411、440、452、550、640。样本为事后诊断，非随机、非代表性，不用于估计全体错误成因比例。没有使用test225选型。

审阅全部8张32帧总览（256张采样帧的导航图），逐帧内容定位后核对10组原图/原生预缩放PNG。原图RGB哈希与CPU准备记录一致；采样帧号、PTS及处理网格与历史记录核对通过。Qwen图像处理器第二阶段网格与预缩放尺寸一致。本次未重建并比对历史完整输入Tensor，不能声称做了完整像素输入回归。

总览仅用于导航，不能凭缩略图判定清晰度。PNG保存原图与缩放图；对话中的JPEG仅为显示副本。由助手人工审阅，非独立人工标注；未连续播放所有视频，事件完整性不确定时明确保留不确定。

## 逐题结论

- **294（unconfirmed）**：32帧中包含多类蜘蛛角色；所核对159.95秒原图/缩放图均能分辨主要人物。题目要求证明某角色在整个视频中未出现，不能凭该帧确认完整否定证据，也未找到原图清楚而输入丢失的关键角色细节。

- **298（not_supported）**：篝火/企鹅场景已入帧。198.99秒原图本身有模糊、火焰遮挡，缩放仍保留主体。相同视觉配置无字幕及原对齐均答C，连续字幕答A。不能将本次错误直接归因为分辨率；一帧也不能完整认证持火把角色计数。

- **405（weak_candidate_only）**：41.67秒及521秒可见表演者，远景人物缩放后更小；原图有额外服饰/身体细节。但源画面亦模糊、存在遮挡及多人身份区分需求，仅据这两帧不能独立认证完整表演者人数。唯一弱候选，未达到明确分辨率瓶颈标准。

- **411（not_supported）**：均匀采样间隔约15.38秒；开场事件计数需要检查未覆盖的连续过程。0秒原图/缩放图均能辨认摩托与骑手。只提高空间分辨率无法补入间隔中的事件；未完整播放开场，不能断言准确缺失了哪些事件。

- **440（not_supported）**：517.56秒人物/姓名已入帧，640x360源图缩至512x288后姓名和人物仍可见。题目要求翻白眼、移动与差点漏拍之间的事件关联；单张人物图不能认证。没有明确细节消失证据。

- **452（not_supported）**：均匀帧含多段不同狗的片段及大面积蓝边；核对419.22秒原图/缩放图是另一只躺地狗，不能认证目标黑白狗从枕头出现的完整情景。蓝边确实耗用面积，但去边/放大不能补入未采到的目标过程，不能据此立新模块。

- **550（not_supported）**：2121.24秒女性面部近景原图/缩放图均保留表情线索；是否对应题述人物关系/完整情绪仍需上下文。无字幕及原字幕同视觉答D，连续字幕答B。没有证据说明恢复分辨率是此误伤的核心解法。

- **640（not_supported）**：1238.44秒商品/价签部分入帧，缩放后$1.00及3/4/5编号仍可辨；该帧不含五件商品猜价与实际价的完整对应，扩大该帧不能保证完成差值比较。无字幕及原字幕同视觉答A，连续字幕答C。

## 主要痛点与边界

1. 证据覆盖/事件完整性与清晰度不同，已有帧无法证明首次、缺席、连续动作和多次计数时，提高分辨率不能填补时间空缺。
2. 298、550、640在同视觉配置下，无字幕和原对齐字幕答对，连续字幕答错。这支持“新增文本/提示变化与具体误伤相关”，不证明分辨率没有任何作用，更不能据此产生未经验证的答案覆盖规则。
3. 405存在小目标退化，但源图模糊、遮挡和角色区分并存；尚未把空间分辨率从其他成因中隔离。单个弱例不足以启动新模块工程。
4. 本轮没有检查新Codec canvas/patch保留情况，不能把Frames结论直接推广为Codec机制的失败或改进空间结论。

## 后续

保留既有Frames-32＋连续字幕的总体收益以及本次负诊断。停止以“需要再加一个模块”为由开发视觉细节分支。不新增选帧、OCR、裁判或字幕规则，不对这8题逐题调参。优先整理重建与字幕成果；未来只有获得多个明确证据充分而缩放丢细节的案例，才重新讨论一次冻结配置的空间预算对照。
