# 自动条件证据核查 v2：先3题接口门槛，再固定30题

2026-11-04，分支feat/air-visual-evidence。保留condition_clips_v1、A.I.R.及所有旧成果；本版本独立代码、协议、断点和结果。

## 失败依据与本轮目标

v1在12题96个任务中88份最终报告非法，48份达到384新token上限，11/12联合报告非法。事实、长原帧号、条件、自述充分性混合在复杂JSON中，超出本轮Mage可靠遵循能力。另有秒/帧混用、模板照抄、仅目标出现却声称充分。不能用宽松解析把失败转成成功。

本轮先检验简化接口的稳定性，再检查语义。格式成功不是完整条件判断成功，不计算QA涨点，不叠加字幕/API/答案覆盖，也不进入全量。

## 冻结设计

保持8全局帧、6个不重叠12秒窗口、每窗口4帧、联合最多32帧及原始时间位置。检索沿用v1的确定性多查询规则，首次/开头优先前24秒、最终优先后24秒；不按题号设置窗口。复用旧CLIP视频特征；新增全局短观察作为一个自动查询，原完整题目/选项与显式子事件始终保留。最多5个查询，CLIP完整分块，不截断原题。

每个阶段拆成两个调用：①最多64新token的短自然语言观察（不要求JSON、数字引用、最终答案）；②固定顺序的逐条件状态与证据单元代码，使用token约束生成，每条件恰好两个token。U=未知/证据不足，P=部分证据，E=模型声称充分；U后只能N，P/E后只能选本次可见的G或0..5。G是全局8帧，数字是程序确定的片段编号。程序保存原帧号和秒数的映射，不让模型输出长帧号或把秒数猜成帧号。

代码限制只保证引用属于允许的证据单元，绝不保证它支持该条件；所有E均标记model_claimed_unverified。首次/最终/顺序另作程序覆盖检查，仍不能证明没有更早事件。自然语言重复、截断和空输出独立统计，不用格式通过冒充语义通过。短观察不赋予逐帧认证。

每题8阶段×2调用=16次；30题最多480次，无格式修复重试。短观察最多64token，条件代码最多2×条件数+1。复用smoke3的3题成果，其余27题最多432次调用。

## 固定样本与隔离

使用原有Video-MME开发180题，不引入新数据。固定旧诊断12题；从剩余视频按固定哈希排序各选9道medium和long，每个新增视频最多一题，得到30题。不得按真值、旧预测或人工时间段选新增题。smoke3固定379（首次）、454（事件）、625（多事件顺序），包含在30题内，共用逐题断点。

新增18题仅作原开发池的覆盖性诊断，不是独立测试。旧12题可在完成后对照旧人工时间段；新18题只输出未标注审阅包，不能捏造正确证据率。

自动init/preflight/run禁止读取人工定位、标签和旧答案；离线summarize可在阶段完整后读取旧12题人工参照。3题完成且接口门槛通过后才开放30题：全部16调用/题存在、代码长度/引用合法、观察非空且无明显重复循环，观察达到上限比例不超过25%。这只是工程门槛。3题报告如显示仍不可信，应先停下人工审阅，不自动扩大。
