# 问题相关完整帧与运动画布的融合

## 问题与目标

在离线长视频问答中，运动区域可能遗漏与问题相关的静态细节。以固定 K=20 为主结果，研究能否减少语义完整帧替换，同时保持问答准确率。K 表示每题替换上限。

## 设计

Mage-VL 对完整视频按编码信息选取 patch，组织为目标 32 个画布。AKS 独立使用原视频候选帧的 BLIP ITM Large 逐题分数与发布的 32 帧选择结果。按时间四分区排序，匹配邻近画布，保留首个有效画布。提高 K 时保留低档已有的帧和位置，加入后续候选；发生位置碰撞时实际替换数会降低。换入整帧并更新 patch 时空坐标，沿用同一 Mage 模型、贪心解码和无外部字幕提示。

## 实验结果

本地 VideoMME 共 238 个视频、714 题；短、中、长分别有 219、258、237 题。[完整预算表](all_budgets.csv) 覆盖九档混合策略与纯 AKS。表中完整帧数对混合组表示替换次数，对纯 AKS 表示输入完整帧数。

|策略|短|中|长|总体|平均完整帧数|
|---|---:|---:|---:|---:|---:|
|原版 K=0|166|164|125|455/714（63.73%）|0|
|固定 K=20|167|176|142|485/714（67.93%）|13.74|
|纯 AKS|164|177|137|478/714（66.95%）|31.99|
|短4、中20、长20（事后回放）|167|176|142|485/714（67.93%）|10.50|

在 237 道长视频题上，上限 4 的同位置中点帧对照答对 126 题，AKS 精选答对 136 题，原版答对 125 题。

## 结论与复核

固定 20 在已测统一预算中总体最高，较原版净增 30 题。两档长度规则回放少用约 23.6% 替换帧，三个时长组正确数均与固定 20 持平。此规则在已见样本上选定，同分仍可能包含逐题得失；需在独立视频验证。视觉网格相同时，替换数下降能否减少端到端耗时需要实测。
