# 固定 K=20 画布下的字幕对齐与视频内检索

## 设计目的与问题

离线 VideoMME 子集包含 238 个视频、714 题。运动画布与问题相关完整帧可以互补，但融合后的视觉时间覆盖会发生变化。我们检验两个问题：字幕锚点是否也应随画布更新？当长视频字幕超出预算时，全片对白检索能否比纯时间选段保住更多正确答案？

## 实现思路

A 使用原生 Codec 画布及原时间字幕。B 将视觉输入换为 AKS＋Codec 固定 K=20，沿用 A 的字幕。C 使用与 B 相同的视觉输入，从融合后保留下来的 patch 和整帧的来源时刻重新匹配 SRT，每个命中句最多补前后各一句（间隔不超过 2 秒），随后去重，按时间合并并保留时间戳。

压缩实验沿用 C 的画面与问答提示。C 在 2048 个字幕 token 以内且有命中时，两组照用原文。超限时，时间组沿时间序列分散取段；混合组先分配至多 1536 token 给时间段，再用题干对同一视频全片的连续字幕短段做 BM25 排序，补充 C 之外的正分段。余量由时间段回填。短段最多三句，保留整句，按模型 tokenizer 核实含时间戳的总长。无可用 SRT 时保留空文本；有 SRT 但无时间命中时混合组可尝试检索。

## 最终结果

| 方法 | 短（219题） | 中（258题） | 长（237题） | 总体正确／714 | 准确率 |
|---|---:|---:|---:|---:|---:|
| A · 原视觉与原字幕 | 176 | 183 | 162 | 521 | 72.97% |
| B · 融合视觉＋原字幕 | 176 | 194 | 166 | 536 | 75.07% |
| C · 融合视觉＋重新对齐字幕 | 175 | 181 | 149 | 505 | 70.73% |
| 时间选段 · 2048 | 175 | 180 | 142 | 497 | 69.61% |
| 时间＋BM25 · 2048 | 175 | 179 | 150 | 504 | 70.59% |

B 是本批准确率最高的配置。B 比 A 改对 34 题、改错 19 题；B 与 C 配对时 B 独对 46 题、C 独对 15 题。旧字幕独对的 89 题中 B/C 各保住 75/55 题；纯视觉独对的 53 题各补回 24/25 题。

长视频中检索相对同预算时间组选段改对 17、改错 9，净增 8 题（+3.38 个百分点）；相对未压缩 C 改对 17、改错 16。长视频字幕中位数由 C 的 3004 降至 2034 token（−32.3%）。全体 714 题检索比时间组多答对 7 题，比 C 少答对 1 题。结果支持把 BM25 用于限预算的长字幕；压缩仅统计字幕 token，准确率最高的 B 仍作为主结果。
